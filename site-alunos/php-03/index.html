Na L2 você viu o caminho rota → controller → view num mini-Laravel. Agora o playground traz um mini-Laravel maior, com rotas e Blade, para você ver o que o Laravel faz de verdade. Tudo começa no routes/web.php, e uma rota pode responder de três jeitos: ① uma função (bom para testar rápido); ② um controller (o jeito do dia a dia); ③ Route::view, para uma página que só mostra uma view, sem lógica nenhuma. A view já está em Blade: {{ $escola }} faz o papel do <?= $escola ?> da L2.

  
Experimente: crie Route::view("/contato", "contato") com uma view nova que mostra o e-mail da escola, e visite /contato de novo.







  
Um pedaço da URL entre chaves vira um parâmetro da função, na ordem em que aparece. Com ? no fim ({nome?}), ele é opcional, e o parâmetro da função precisa de um valor padrão. Para aceitar só certos valores, use ->whereNumber("id") (só números) ou ->where("slug", "[a-z-]+") com uma expressão regular: se a URL não bater, a rota é ignorada e o resultado é 404.

  
Experimente: crie a rota /tabuada/{n}, só com números, que devolve 7 x 2 = 14 para /tabuada/7. Depois visite /blog/Post_1 e explique o 404.







  
Se você escreve /cursos/3 em 20 links e um dia a URL muda para /formacoes/3, tem que caçar os 20. Por isso a gente dá um nome à rota com ->name("cursos.show") e monta os links com route("cursos.show", 3): mudou a URL, os links acompanham sozinhos. O costume é assunto.ação. fn () => "Início" é a forma curta de function () { return "Início"; } (a arrow function do JavaScript). No Laravel de verdade, route() devolve o endereço completo (http://localhost:8000/cursos/3); aqui, só o caminho.

  
Experimente: mude a URL da rota cursos.show para /formacoes/{id} e execute: os links mudam sozinhos. Depois chame route("cursos.editar") e leia o erro.







  
Três ferramentas do dia a dia. abort(404): o curso pedido não existe? Pare tudo e responda 404 (ou abort(403) para "acesso proibido"). Route::redirect: uma URL antiga manda para a nova (resposta 302). Grupo: Route::prefix("admin")->name("admin.")->group(...) coloca /admin na URL e admin. no nome de todas as rotas de dentro, sem repetir. O use ($cursos) deixa a função enxergar a variável de fora: em PHP, a função não enxerga sozinha.

  
Experimente: crie dentro do grupo a rota /admin/notas com nome admin.notas. Depois faça /cursos/2 responder abort(403).







  
As views do Laravel terminam em .blade.php: o Blade é o jeito do Laravel escrever HTML com buracos. {{ $nome }} faz o papel do <?= $nome ?>, com um bônus de segurança: ele escapa o HTML. Se alguém cadastra o nome <script>, o Blade troca < por &lt; e o código não roda (isso evita o ataque chamado XSS). Dentro das chaves vale qualquer expressão PHP. {!! $bio !!} mostra sem escapar: use só com HTML em que você confia. {{-- … --}} é comentário e não vai para o HTML.

  
Experimente: troque a bio por <script>alert("hackeado")</script> e clique em 🌐 ver como página: compare a linha com {{ }} e a com {!! !!}.







  
No Blade, as estruturas de controle viram diretivas que começam com @. @if / @elseif / @else / @endif é o if de sempre, sem chaves. @unless é um "se não". @isset($x) só mostra se a variável existir, e @empty($lista) só mostra se ela estiver vazia. Toda diretiva que abre precisa fechar: @if → @endif.

  
Experimente: mude a média para 6 e depois para 3. Passe também "observacao" => "Ótima participação" e veja o @isset aparecer.







  
@foreach ($cursos as $curso) … @endforeach repete um pedaço do HTML. Dentro dele o Blade cria a variável $loop, que diz onde você está: $loop->iteration (1, 2, 3…), $loop->index (0, 1, 2…), $loop->first e $loop->last (true no primeiro e no último), $loop->count (total) e $loop->remaining (quantos faltam). E o @forelse é um foreach com plano B: o que estiver depois do @empty aparece quando a lista vem vazia.

  
Experimente: coloque dois nomes na lista de alunos e veja o plano B sumir. Depois mostre (faltam {{ $loop->remaining }}) em cada curso.







  
Todas as páginas de um site têm o mesmo cabeçalho, menu e rodapé. Em vez de copiar, você escreve um layout (resources/views/layouts/app.blade.php) com buracos marcados por @yield("conteudo"). Cada página começa com @extends("layouts.app") e preenche os buracos com @section("conteudo") … @endsection. Para um texto curto, use a forma de uma linha: @section("titulo", "Início"). O segundo valor do @yield é o padrão, usado quando a página não preenche.

  
Experimente: crie um terceiro buraco @yield("rodape") no layout e preencha só na home. Depois mude o texto do <header> no layout e veja as duas páginas mudarem.







  
O layout resolve o esqueleto. Para um pedaço que se repete em vários lugares (o menu, o card de um curso), crie um partial e coloque onde quiser com @include("partials.menu"). O partial enxerga as variáveis da view que o incluiu, e você pode mandar mais dados no segundo argumento: @include("partials.card-curso", ["curso" => $c]). Repare no menu: os links usam route() dentro de {{ }}.

  
Experimente: adicione um quarto curso. Depois crie o partial partials.rodape e inclua no fim da página.







  
Um componente é um partial que se usa como se fosse uma tag HTML. O arquivo resources/views/components/alerta.blade.php vira a tag <x-alerta>. O que vai entre a abertura e o fechamento chega na variável $slot; os atributos chegam como variáveis, e o @props define os valores padrão. Com dois-pontos (:tipo="$nivel"), o valor é uma expressão PHP, não um texto. É só uma introdução: os componentes voltam nos formulários (L5).

  
Experimente: crie o componente <x-botao> que mostra <button class="botao">{{ $slot }}</button> e use no painel.







  
O Blade não é mágica: antes de rodar, o Laravel compila a view, ou seja, troca cada {{ }} e cada @diretiva por PHP comum, e guarda o resultado em storage/framework/views para não refazer a cada visita. Este exemplo mostra o PHP que sai de uma view. Repare: {{ $x }} vira echo e($x) (o e() é quem escapa), {!! $x !!} vira echo $x, e o @foreach ganha umas linhas a mais para preparar o $loop.

  
Experimente: coloque um @unless e um {{-- comentário --}} na view e veja no que eles viram.







  
Tudo junto, do jeito que fica num projeto Laravel: um model com os cursos (na L4 eles vêm do banco), um controller com index (a lista) e show (um curso, ou 404), rotas nomeadas com whereNumber, um layout e duas páginas que estendem o layout, com links feitos por route(). Clique em 🌐 ver como página.

  
Experimente: adicione o curso de JavaScript no model. Depois crie a página /sobre com Route::view, estendendo o mesmo layout, e coloque o link no menu.
